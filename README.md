# AI Decision Audit Report Generator

**An AI-powered audit-report generator for fraud, AML, and KYC decision systems used by Nigerian financial institutions.**

The system allows a client to upload CSV decision logs, automatically maps the data to a normalized schema, performs drift analysis, and generates a plain-English audit report.

It also includes a chat endpoint that allows users to ask questions directly about their uploaded data.

---

## How It Works

```text
CSV Upload
    ↓
Column Mapping
    ↓
Data Normalization
    ↓
Drift Analysis
    ↓
Audit Report
    ↓
PDF Export
    ↓
Data Chat
```

### 1. Data Ingestion

Clients upload their decision logs as CSV files.

The system uses AI-assisted column mapping to identify and map uploaded columns to the normalized schema, reducing the need for clients to manually reformat their data.

### 2. Drift Analysis

The system compares a **baseline period** with a **current period** to identify changes in the decision data.

Population Stability Index (PSI) is used for drift detection. The calculation is performed using pure Python mathematics and does not require an LLM call.

### 3. Audit Report

The analysis is converted into a plain-English audit report containing the key findings from the uploaded data.

### 4. PDF Export

The generated report can be converted into a downloadable PDF for sharing and review.

### 5. Data Chat

The chat endpoint allows users to ask questions about their uploaded data using the normalized records and drift results generated by the pipeline.

# Project Structure

| File            | Purpose                                                           |
| --------------- | ----------------------------------------------------------------- |
| `main.py`       | FastAPI entry point and application configuration                 |
| `ingest.py`     | CSV upload and AI-assisted column mapping                         |
| `drift.py`      | PSI drift detection and related calculations                      |
| `report.py`     | Generates the plain-English audit report                          |
| `pdf_export.py` | Converts reports into downloadable PDFs                           |
| `pipeline.py`   | Connects ingestion, drift analysis, reporting, and PDF generation |
| `chat.py`       | Provides the data-questioning chat endpoint                       |
| `llm_client.py` | Centralized LLM API integration                                   |

Keeping the LLM integration in `llm_client.py` also makes it easier to change providers without modifying the rest of the application.

# Setup

## Requirements

* Python
* FastAPI
* An Anthropic API key
* VS Code or another Python development environment

## 1. Open the Project

Open the project folder in VS Code.

Open a terminal using:

```text
Terminal → New Terminal
```

## 2. Create a Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac / Linux

```bash
python -m venv venv
source venv/bin/activate
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure Environment Variables

Copy:

```text
.env.example
```

to:

```text
.env
```

Then add your:

```text
ANTHROPIC_API_KEY
```

## 5. Start the Server

```bash
uvicorn main:app --reload
```

The API will be available at:

```text
http://localhost:8000
```

Interactive API documentation is available at:

**http://localhost:8000/docs**

# Try It End to End

The application can be tested directly through FastAPI's interactive documentation.

### Generate an Audit Report

Use:

```text
POST /report/generate
```

Upload:

* `baseline_file` — an earlier period representing normal activity
* `current_file` — the period currently being audited

The endpoint returns the audit results as JSON, including:

* Report narrative sections
* Drift results
* Normalized data
* Row counts

### Generate a PDF Report

Use:

```text
POST /report/pdf
```

Upload the same baseline and current files to generate a downloadable PDF version of the audit report.

### Ask Questions About the Data

Use:

```text
POST /chat/ask
```

The endpoint can receive the `drift_results` and `normalized_rows` produced by the report pipeline and answer questions about the uploaded data.

### Test Column Mapping

The standalone:

```text
POST /ingest/csv
```

endpoint can also be used when you only want to test how a single CSV file is mapped to the normalized schema.

# Current Scope

The first version deliberately focuses on a **CSV-first workflow**.

This keeps the initial implementation simple while providing a practical foundation for a client pilot.

### Currently Included

* CSV upload
* AI-assisted column mapping
* Data normalization
* PSI drift detection
* Plain-English audit reports
* PDF report generation
* Data-questioning chat endpoint
* FastAPI API
* Centralized LLM integration

---

# Not Included in V1

### Frontend

A Next.js frontend has not yet been implemented.

The current version can be used through FastAPI's interactive API documentation.

### Bias and Fairness Metrics

Fairness metrics are deferred to **v2**.

Implementing meaningful fairness analysis requires appropriate protected-attribute data and proper consideration of applicable privacy and regulatory requirements. This is therefore intentionally not treated as a simple add-on.

### Live API / Webhook Ingestion

Live API and webhook ingestion are also deferred to **v2**.

The first version uses CSV uploads to establish a practical pilot workflow before introducing direct system integrations.

# Project Goal

The goal of this project is to make AI decision-system auditing more accessible to financial institutions by turning raw decision logs into **clear, explainable, and actionable audit reports**.

The current CSV-first approach provides the foundation for a future platform supporting more advanced monitoring, integrations, and audit capabilities.
